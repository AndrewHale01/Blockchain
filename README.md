# Lucky Block Lottery

Навчальний React-застосунок для локальної Ethereum-лотереї. Квиток коштує
`0.01 ETH`; гаманець може приєднатися один раз за раунд, а переможця визначає
власник контракту. Після вибору переможцю автоматично надсилається весь приз.

> Вибір переможця використовує дані блоку для псевдовипадкового числа. Це
> придатно лише для локального демо й не є безпечним способом проводити
> розіграші з реальними коштами.

## Запуск локально

1. Запустіть Ganache UI на `127.0.0.1:7545` з network ID `5777`.
2. У корені проєкту скомпілюйте й розгорніть контракт:

   ```sh
   truffle migrate --network development
   ```

3. Додайте локальну мережу Ganache у MetaMask. Для Ganache за замовчуванням
   Chain ID зазвичай `1337`, а RPC URL — `http://127.0.0.1:7545`.
4. Встановіть frontend-залежності й запустіть React-застосунок:

   ```sh
   npm install
   npm run dev
   ```

Адреса контракту автоматично читається з `build/contracts/Lottery.json` для
поточного network ID. Якщо потрібно задати адресу вручну, створіть `.env.local`
у корені проєкту зі змінною `VITE_LOTTERY_ADDRESS`.

## Перевірка

```sh
truffle test
npm run build
```
